## Project Structure and Python Tips
- Recommended folder structure per session: `/source`, `/data` (or `/ops`), `/log` (or `/error`)
  - Avoids dumping everything in one directory; enables clean handoff to teammates
- Absolute vs. relative paths:
  - Absolute paths break when shared (NetID-specific); relative paths are portable
  - Workaround: store your NetID as a variable, build paths from it
- Advanced import tip: create a single `imports.py` script, then use `from imports import *` in
  any notebook — equivalent to R's library-loading pattern; can also use pre-bundled packages on
  GitHub
- Prompt engineering tips surfaced during class:
  - Add `#` comments asking AI to explain each step
  - Tell AI: "be succinct, one line where possible"
  - Tell AI: "use the most efficient method, I have millions of rows"
  - Use `df.describe()` and pass the output to AI to catch anomalies
- Big data preview: current pipeline (load → clean → split → analyze) only works for small
  datasets. For large datasets: process file by file, then aggregate; never load billions of rows
  at once
