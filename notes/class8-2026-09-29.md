## What a regression does
- Finds the best-fit line through the data by minimizing the sum of squared residuals
  (OLS = Ordinary Least Squares).
  - "Best" is specific: squared loss, not absolute deviation or any other loss function.
  - Y-hat (fitted value) is the closest point on the parameter plane to the actual y.
  - Residual = y − y-hat, the estimate of the unobservable error term.
- We can't perfectly explain the world, so the error term captures unobserved influences.
  - Example: demand estimation where only price is observed, but brand, advertising and location
    also matter.
- Watched videos in class to build intuition (different voice narrating).

## Linear vs. non-linear models
- A model is linear if it is **linear in its parameters**, not necessarily in the variables.
  - Non-linear: `y = a × b × x + u` (parameters a and b interact).
  - Non-linear: `y = a + b × x × u` (a parameter interacts with the error term).
  - Linear: `y = a + b × x1 × x2 + u` (the x's interact, but the parameters stay separate).
  - Linear: `y = a + b × x + c × x² + u` (quadratic, but the parameters are separate).
- Implication: very flexible polynomial models (degree 10, etc.) are still "linear" regressions.

## Key concepts to know for the course
The instructor wants students to be able to explain:
- What "simple" means: one control variable (x).
- What "linear" means: linear in its parameters.
- What OLS does: minimizes the sum of squared residuals.
- **Multiple linear regression**: adds several x's; each beta measures the effect of one x on y,
  holding the others constant.
  - Will be the main tool for demand estimation (e.g. Zappos shoe data: price, brand and color all
    matter).
- **OLS consistency**: as the sample size grows, estimates converge to the true (unknown) parameters.
  - More data generally means more precise estimates, but only when the OLS assumptions hold.
- **Sum of squares**: SSE (unexplained) + SSR (explained) = SST (total variation).
  - R² = SSR / SST, i.e. the share of variation explained.
- **Heteroskedasticity**: the error variance changes across observations; OLS slope estimates still
  centre on the truth, but the spread of the residuals changes (and default standard errors are off
  — see our exercise 4 below).
- **Selection bias**: running a regression only on a selected sample (e.g. successful startups)
  distorts the estimates significantly.
