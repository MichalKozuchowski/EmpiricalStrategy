## Terminal and Cluster Commands
- What is terminal: a text prompt for navigating and monitoring the computer without clicking
- Why we have a text prompt: allows us to see the health of the system
- Useful commands (extra, not required):
  - `pestat` — shows nodes and running jobs
  - `pestat -g` — shows GPU usage
  - `top` — live view of processes on the head node
  - `ls` — lists files in current directory
  - `pwd` — present working directory (tells you where you are)
- **Slurm**: the software that manages, prioritizes, and launches jobs on the cluster

## Python Basics
- Three parts of a typical Python script:
  1. **Imports** — libraries that extend Python's capabilities (e.g., pandas, BeautifulSoup)
  2. **Definitions** — custom functions (e.g., `def add(a, b): return a + b`)
  3. **Execution** — running the code (often handled automatically in Jupyter)
- Jupyter notebooks: the primary environment for class work, like Word but for code
- Key skill: prompting AI correctly, then checking whether the output does what you asked
  - Same task, slightly different prompt can produce hundreds of lines vs. three
  - Learning to prompt efficiently is a core class objective
