## Pandas and First Dataset: Chicago Taxi Data
- Basic pandas script structure: import → define data → do work → run
  - `import pandas as pd` (convention: alias as `pd` to avoid typing `pandas.` repeatedly)
  - Load only the first 1,000 rows to start: `pd.read_csv(fname, nrows=1000)`
- Chicago taxi dataset columns: trip ID, start/end time, duration, miles, census tract,
  community area, fare, tip, tolls, total, payment type, company, lat/long
- Useful exploratory commands: `df.iloc[0]`, `df.columns`, `df.head()`
- Column name gotcha: spaces in column names break dot notation; use bracket notation
  with quotes instead
- Creating new columns: e.g. `df['mph'] = df['trip_miles'] / df['trip_seconds'] / 3600`
  - Division by zero (zero-second trips) produces `inf`: a data quality issue, not a code bug
- Data cleaning conditions to filter on:
  - `trip_seconds > 0`
  - Trip actually goes somewhere (`miles > 0`)
  - Positive prices
  - Store as `df1 = df[condition1 & condition2 & condition3]` (preserves original `df`)
- Unit tests: write assertions that must always be true (e.g. market shares sum to 100, size > 0)
- Market share calculation: count trips per company / total trips
  - Definition is not obvious: quantity, revenue, distance-weighted all valid
  - Verify with fake data: create synthetic data with known shares, confirm the function
    returns them correctly
